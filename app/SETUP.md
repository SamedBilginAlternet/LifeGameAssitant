# MEMOIR_LOG — Local setup

## Prerequisites

- Flutter `>=3.8.0 <4.0.0` (matches `/workspace/prova` locally).
- Xcode (for iOS) and Android Studio / SDK (for Android).
- A Supabase project — free tier is fine.

## First-time bootstrap

The repo ships only `lib/` and `pubspec.yaml`. Platform folders (`ios/`, `android/`, etc.) are generated by Flutter on first setup so they always match your local toolchain version.

```bash
cd app
flutter create . --org com.samed.memoirlog --project-name memoir_log --platforms=ios,android
flutter pub get
```

`flutter create` with an existing `lib/` directory **adds** the platform folders without overwriting any source files.

## Environment variables

The app reads its config from `--dart-define` flags. Two are required:

| Var                  | Where to find it                                               |
|----------------------|----------------------------------------------------------------|
| `SUPABASE_URL`       | Supabase dashboard → Project Settings → API → Project URL      |
| `SUPABASE_ANON_KEY`  | Supabase dashboard → Project Settings → API → anon public key  |

### Run command

```bash
flutter run \
  --dart-define=SUPABASE_URL=https://<project>.supabase.co \
  --dart-define=SUPABASE_ANON_KEY=<anon_key>
```

### VS Code launch config

Copy `.vscode/launch.json.example` to `.vscode/launch.json` and fill in your values. The example is gitignored except for the `.example`.

## Database migrations

```bash
cd ../supabase
supabase db push
```

Or paste each `migrations/000X_*.sql` file into the Supabase SQL editor in order.

## Auth providers (Apple + Google)

Configure these in your Supabase dashboard (Authentication → Providers). The app's login screen is provider-agnostic — it calls `supabase.auth.signInWithOAuth(...)` with whichever provider the user picks. No client-side keys required.

## Smoke test (Phase 0 done-when)

After running with your Supabase URL + anon key:

1. App boots → boot sequence → login screen.
2. Sign in with Apple or Google → trigger creates a `profiles` row.
3. Land on the Timeline → see `> NO ENTRIES YET. LIVE A DAY.`

If you see that line, Phase 0 is done.
